# Changelog

## v0.3.0 — 2026-07-20

- Added first-class object selection, movement, deletion, nudging, and hit testing.
- Replaced stack-based undo with 200-entry command history and redo.
- Added sticky notes and inline editing for sticky and text objects.
- Added local-first autosave, multiple-board management, and JSON import/export.
- Replaced pixel erasing with undoable object erasing and added selection restyling.
- Added Replace/Add template choices, richer template metadata, notes, and prompt copying.
- Added viewport pan/zoom, content-bounds PNG export, autosave status, cached template loading, and regression tests.
